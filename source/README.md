# Search Agent vNext

Hatırladığınız içerikle Windows dosyalarını bulun. Qwen3-Embedding-0.6B ile yerel anlamsal arama; Türkçe/İngilizce arayüz, açık/koyu tema ve belge önizlemesi.

**Programın tamamını, kullanımı, sistem gereksinimlerini ve sınırları [PROGRAM.md](PROGRAM.md) dosyasından okuyun.**

EXE: Windows ZIP'ini tamamen çıkarın ve SearchAgent.exe'yi açın. Klasörleri seçin, **Aramaya hazırla / güncelle** düğmesine basın, sonra hatırladığınız içeriği yazın.

Birden çok disk ve UNC paylaşımı eklenebilir. Kopan bağlantılarda eski kayıtlar korunur; yeniden bağlandıktan sonra güncelleyin. Gerçek NAS testi bu teslimin kapsamına dahil değildir.
